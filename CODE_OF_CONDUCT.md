# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique ideas rather than people, and welcome newcomers.
Harassment of any kind is not tolerated.

To report a problem privately, contact the maintainer through their GitHub profile (@madhavbuilds).
